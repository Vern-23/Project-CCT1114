Independent Learning

While completing this project, we independently learned more about Aritificial Intelligence (AI), including its applications, benefits and limitations. We also learned how AI is used in different areas such as manufacturing, banking, customer service, transportation and human resources. Besides learning about AI, we also improved our skills in creating a website using HTML and CSS.


Important of AI

Artificial Intelligence is an important topic because it is becoming increasingly common in modern life and workplaces. AI can help people complete tasks, analyse information, solve problems and improve productivity. Understanding AI can help students prepare for future continues to develop.


New Skills Acquired

Through this project, we gained new knowledge about how AI is applied in different industries. We also learned how to organise information and present, we improved our HTML and CSS skills, adding images, organising content and designing webpage layouts.


Skills to Develop

In the future, we would like to learn more about AI, machine learning and programming. We also want to improve our web development skills, especially JavaScript. Developing these skills can help us understand how AI systems work and create more interactive websited and applications.


Future Learning Plan

We plan to continue learning about AI through online courses, tutorials, videos and practical exerceses. We can also follow new developments in AI and practise programming regularly. By learning independently, we can gradually improve our knowledge and skills even after completing this project.


Reflection

This project gave us an opportunity to learn independently instead of relying only on classroom lessons. At first, finding and organising information was challenging, but we learned how to search for useful information and apply what we learnded. Overall, the experience helped us become more confident in learning new technologies and working on a project independently.

W3School W3School provides tutorials about HTML, CSS,JavaScript, Phython and other web development technologies. The tutorials are simple to understand and include examples that learners can practise. Students can continue using W3Schools to improve their web development and programming skills.
Codeacademy Codeacademy provides interactive lessons about programming languages such as Python, JavaScript, HTML and CSS. It allows learners to practise coding directly while learning new concepts. Students can use Codeacademy to develop their programming skills and learn new technologies through interactive exercises.
Google AI Google AI provides information and learning resources about Artificial Intelligence, machine learning and AI technologies. It helps learners understand AI concepts and learn about developments in AI. Students can use Google AI resources to keep learning as the field continues to develop.
freeCodeCamp freeCodeCamp teaches programming, web development, JavaScript, Python and other technical skills. It provides practical exercises that allow learners to practise what they have learned. Students can use the platform regularly to build their programming skilld and work on practical projects.
Coursera Coursera provides courses about Artificial Intelligence, machine learning, programming, data science and other technology-related subjects. It provides structured courses from universities and organisations, making it easier to learn a topic step by step. Students can use Coursera to learn more advanced AI and programming topics after completing their current studies.
